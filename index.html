⚔️ Knight To Victory

A side-scrolling action game built with Raylib

🎮 Controls

  • Arrow Keys:Move left/right
  • Space:Jump / Attack
  • Left Shift:Sword
  • Left Click:Fireball
  • P:Protection Potion
  • H:Health Potion
  • B:Boost Potion
  • ESC:Pause menu

Built withrayliband WebAssembly
